# QuickJS 2020-07-05 Core Source Files

This directory contains the core source files of QuickJS 2020-07-05 matching the bytecode engine embedded in the Youdao DictPen S7 Pro Falcon runtime (`libfalcon.so`).

These headers and source files are used for opcode/atom analysis, bytecode disassembling/decompiling, and native plugin interop.
